# 语言迷航 · Language Portal

一个移动端优先的多语言互动穿越学习游戏。无需框架、安装命令或 API Key。

## 已实现（v0.2）

- **6 种目标语言**：英语、日语、韩语、法语、西班牙语、德语。
- **36 个剧情关卡**：每门语言各 6 关，围绕问候、问路、买面包、询价、找图书馆、请求重复。
- 目标语言 NPC 对话，三选一答题与自由输入。
- 中文任务说明、句义提示、语言小知识。
- 浏览器语音朗读（自动选择目标语种）、语音转文字输入（取决于浏览器支持与权限）。
- 每门语言独立通关进度、总经验值、跨语言词库、单语言重开。
- 使用浏览器 localStorage 在本机保存，不需要登录或后端服务。

## 试玩

打开仓库中的 **index.html**。这是完整的单文件网页，所有关卡内容和界面都在一个文件里，不引用外部 CDN。

在 GitHub Pages 或其他静态站点发布后可直接通过 HTTPS 地址在手机中玩。注意：仓库目前是 **private**，此仓库尚未设置公开的试玩域名；仅推送文件不会自动提供公开网站。启用 GitHub Pages 时请自行核对账户/仓库的 Pages 权限及发布设置（Source: Deploy from a branch, main / root），或部署到已有静态站点。

## 功能边界

- 这不是对原视频的复刻：故事、人物、关卡与 UI 均为独立设计。
- 自由输入只匹配内置范例和少量可接受的替代表达，**不是 AI 语义理解**。选择正确句子总能过关。
- 麦克风只把语音转写为文字，**没有发音评分**。
- 语音朗读使用设备的 SpeechSynthesis；实际音质与支持的语种取决于系统语音包。
- 某些浏览器的语音识别依赖网络及浏览器提供方，浏览器可能将音频发送给其语音服务；本网页本身不设服务器，也不主动上传进度。
- 本机进度和词库可能在清理浏览器数据后丢失，不同设备不会自动同步。
