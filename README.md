# 语言迷航 · Language Portal

在线玩：https://tusumy.github.io/game-url/

## v0.4 · NPC 自由对话与语音优化

六种语言（英语、日语、韩语、法语、西班牙语、德语），每门 18 关，共 108 关。

- 第一章（1–6）：选择题与基础语音。
- 第二章（7–12）：输入目标语言句子，必要时可求助。
- 第三章（13–18）：NPC 的台词默认隐藏，需先听语音，再独立回答。
- 进度、经验值与单词本继续保存在本地浏览器。

### 声音改进

首页顶部点击「音色设置」，可以为当前语种选择系统中的音色、试听、调节语速、停止播放。默认语速已从 0.82× 调整到 1.00×；支持在系统异步加载音色后刷新选项，并优先选择目标语言的较自然音色。系统 Web Speech API 的具体质量取决于手机、浏览器与语言包，不能保证达到 ElevenLabs 级别。

### NPC 对话模式

进入关卡，向下展开「NPC 自由对话」。

- 离线陪练：可以立即使用，提供简易场景对话与文本相似度通关。它不是通用语义理解，可能错误判定；支持切回原来的闯关题目。
- AI 自由对话：需要用户连接可信任、支持浏览器 CORS 的 OpenAI-compatible Chat Completions HTTPS API。填写 API 基础地址（或完整 chat/completions 路径）、模型、可选密钥，就能让模型扮演当前关卡 NPC，理解非固定回答并在完成任务时解锁本关。
- 可选择让 NPC 回复自动语音播放；也提供浏览器语音转文字按钮。
- API 地址与模型名保存在 localStorage，密钥只在页面内存，不写入仓库、不写入 localStorage；刷新页面需重填密钥。
- 聊天内容会发送给配置的 AI 提供商，可能产生费用。若遇到 CORS 限制，需要自有安全 API 网关。绝不能把私人密钥写入公开源码。
- **本站没有预装免费的 AI 后端**；不配置接口也可以继续玩所有关卡。

## 已知限制

离线判题不支持所有同义表达；模型判断的正确性依赖所连接的提供商；语音识别不等于发音评分；多设备间不自动同步进度。
