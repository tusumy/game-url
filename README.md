# 语言迷航 · Language Portal

移动端优先的多语言互动穿越学习游戏。打开 [线上游戏](https://tusumy.github.io/game-url/) 即可体验，无需账号、API Key 或后端服务。

## v0.3：三个章节、108 关

六种语言：英语、日语、韩语、法语、西班牙语、德语。每种语言 18 关，共 108 关。

- **第 1 章 · 新手村（1–6）**：听 NPC 说话，用选择题或自由输入回答；适合熟悉操作。
- **第 2 章 · 城市求生（7–12）**：餐厅预订、末班车、列车延误、酒店确认、过敏、找银行。**不直接展示选择题**，需要独立输入目标语言句子。
- **第 3 章 · 高压试炼（13–18）**：入城审查、目击证词、症状描述、条件句、解释错误、最终传送门。**隐藏 NPC 台词**，要求先听懂再回答。
- **章节自由跳转**：直接进入第二或第三章，不必刷完简单题。
- **经验系统**：新手关 20 XP、进阶关 35 XP、高压关 55 XP。答错、看翻译、显示台词或求助恢复选择题会扣除本关经验，最低保留 5 XP。
- **独立存档**：每种语言的关卡、分数和句子词库保存在浏览器 localStorage，升级保留老版本已通关的六关。
- **语音**：浏览器朗读 NPC 对话和答案；有兼容的语音识别时可把口语转为输入文本。

## 部署

GitHub Pages 使用 `main` 分支的根目录：

- `index.html` — 游戏界面、进度与交互逻辑
- `advanced.js` — 六种语言各 12 个进阶/高压场景的对话数据
- `README.md` — 项目说明

网站：https://tusumy.github.io/game-url/

本地运行时需同时保存 `index.html` 与 `advanced.js` 在同一目录；独立下载 HTML 不含扩展关卡。

## 已知限制

- 离线输入是**参考答案文本匹配**，不是 AI 自由对话，不会自动识别所有正确的同义表达。因此设有“求助：显示选择题”保证可以过关。
- 语音转文字不是发音评分；音色、口音、语种与识别可用性取决于浏览器、系统语言包和授权，部分浏览器的语音识别需要网络。
- 进度只保存在当前浏览器本机，不跨设备同步；清理站点存储会丢失数据。
- 点击“显示台词”和使用求助会降低本关 XP，不会重置已经获得的其他关卡进度。
- 关卡是原创的简化语言教学示例，暂未做母语者教研审核。

未来可以继续加 NPC 自由对话、语义理解、语法检测、发音评分、分支地图和更长的冒险故事。
